From Connectome to Dissimilarity Matrix

        
The connectivity matrix above is one step from a representational dissimilarity matrix (RDM).
        By computing d = 1 - r for each pair, correlations become distances. The upper triangle of this
        distance matrix, flattened into a vector, is the condensed dissimilarity vector --
        a compact fingerprint of this brain's representational geometry. For 20 regions, that is 190 unique
        values. For a full 300-parcel atlas, it is 44,850 values -- but the principle is identical.
        These condensed vectors can be compared across subjects, or between a biological brain and an
        artificial neural network, using second-order correlation.

Key Terms

    

      

        
BOLD signal

        
Blood-Oxygen-Level-Dependent signal. fMRI measures changes in blood oxygenation as a proxy for neural activity. Active neurons consume oxygen, triggering increased blood flow.

      

      

        
Parcellation / Atlas

        
A division of the brain into discrete regions (parcels). Common atlases: Schaefer (100-1000 parcels), AAL (116 regions), DiFuMo (data-driven). Each parcel gets one averaged time series.

      

      

        
Pearson correlation (r)

        
Measures linear co-fluctuation between two signals. r = 1 means perfectly in sync, r = -1 means perfectly anti-correlated, r = 0 means unrelated. Range: [-1, +1].

      

      

        
Fisher z-transform

        
Converts bounded correlations [-1, +1] to an unbounded normal scale via z = arctanh(r). Required for valid group-level statistics because raw r values are skewed near the bounds.

      

      

        
Connectome

        
A complete map of neural connections. A functional connectome is an N x N matrix of pairwise correlations between all brain regions. A structural connectome counts physical white matter tracts.

      

      

        
RDM (Representational Dissimilarity Matrix)

        
A distance matrix (d = 1 - r) encoding how differently brain regions process information. The upper triangle, flattened, is a condensed vector that fingerprints a brain's representational geometry.

      

      

        
TR (Repetition Time)

        
The time between consecutive fMRI volume acquisitions, typically 0.5-3 seconds. Determines the temporal resolution of the BOLD time series. More TRs = longer scan = more stable statistics.

      

      

        
Confound / Nuisance regressor

        
Non-neural signal sources (head motion, heartbeat, breathing, scanner drift) that contaminate BOLD data. Removed during preprocessing by regression, before computing connectivity.

      

      

        
Docker / Singularity

        
Container technologies that package software with all dependencies. BIDS Apps use Docker for reproducibility, but the underlying tools (nilearn, nibabel, MNE) run without containers via pip install.

      

      

        
NIfTI (.nii / .nii.gz)

        
The standard file format for neuroimaging data. A 3D or 4D array of voxel intensities plus a header encoding spatial orientation. Read/written by nibabel in Python.
