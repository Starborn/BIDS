Functional Connectivity

How correlated brain activity reveals the architecture of neural networks -- from raw time series to dissimilarity matrices, using BIDS tools without Docker.

Introduction to Brain Connectivity

The brain is not a collection of independent regions working in isolation. It is a network. Different areas communicate constantly -- the visual cortex talks to the motor cortex when you reach for something you see, memory regions talk to decision-making regions when you draw on past experience to make a choice. Brain connectivity is the study of these communication patterns.

Two kinds of connectivity

Structural connectivity maps the physical wiring -- the white matter fibers (axon bundles) that physically connect one region to another, like cables between buildings. Functional connectivity maps coordinated activity -- regions that consistently activate and deactivate together over time, whether or not they are directly wired to each other. This module focuses on functional connectivity.

What are brain regions?

A raw fMRI scan contains about 100,000 tiny measurement points called voxels, each roughly 2-3mm across. Individual voxels are noisy. To make the data manageable, we divide the brain into larger regions (parcels) using an atlas -- a pre-defined map that groups voxels into anatomically or functionally meaningful areas. Common atlases define between 100 and 1,000 regions. This module uses 20 regions for clarity.

What is a time series?

During an fMRI scan, the scanner takes a snapshot of the whole brain every 1-2 seconds (the repetition time, or TR). For each brain region, we get a sequence of numbers -- one value per snapshot -- representing that region's activity level over time. This sequence is a time series. If the scan lasts 5 minutes with a TR of 2 seconds, you get 150 numbers per region.

What does the BOLD signal measure?

fMRI does not measure neural activity directly. It measures blood oxygenation. When neurons fire, they consume oxygen, triggering a local increase in blood flow that overshoots the demand. This hemodynamic response changes the ratio of oxygenated to deoxygenated hemoglobin, which has different magnetic properties -- and that is what the scanner detects. The signal is called BOLD: Blood-Oxygen-Level-Dependent.

What is correlation?

Correlation measures how similarly two signals fluctuate over time. If region A's activity goes up whenever region B's goes up, and down when B goes down, they are positively correlated. If A goes up when B goes down, they are anti-correlated. If there is no pattern, they are uncorrelated.

The Pearson correlation coefficient (r) quantifies this on a scale from -1 to +1. These are its bounds -- r can never go below -1 or above +1. That is what "bounded" means. A value of r = 1 means perfect lockstep, r = -1 means perfect opposition, and r = 0 means no linear relationship. "Linear co-fluctuation" simply means the two signals tend to rise and fall together (or in opposition) in a proportional way.

Pearson correlation: r = cov(X, Y) / (sigma_X * sigma_Y) where cov is covariance and sigma is standard deviation. Range: [-1, +1]

What is a connectivity matrix?

If you compute the correlation between every possible pair of brain regions, you get a symmetric matrix -- a grid where rows and columns are regions and each cell contains the correlation between that pair. The diagonal is always 1 (each region is perfectly correlated with itself). This matrix is the functional connectome. It captures the full pattern of which regions co-activate with which others.

What is a dissimilarity matrix?

A simple transformation -- d = 1 - r -- converts correlations into distances. High correlation (r close to 1) becomes small distance (d close to 0), meaning the regions are representationally similar. Low or negative correlation becomes large distance. The upper triangle of this matrix, flattened into a single vector, is a compact fingerprint of the brain's representational geometry. These fingerprints can be compared across people, or between a brain and an artificial neural network.

Key concepts at a glance

BOLD signal
Blood-Oxygen-Level-Dependent signal. fMRI's indirect measure of neural activity via blood oxygenation changes.
Parcellation / Atlas
A map dividing the brain into discrete regions. Common: Schaefer (100-1000), AAL (116), DiFuMo (data-driven).
Time series
A sequence of values over time -- one number per brain snapshot (TR). The raw material for connectivity analysis.
Pearson r
Measures linear co-fluctuation. r=1: perfect sync. r=-1: perfect opposition. r=0: unrelated. Bounded [-1,+1].
Fisher z-transform
Converts bounded r to unbounded z via arctanh(r). Required for valid group statistics because raw r is skewed near bounds.
Connectome
A complete map of brain connections. Functional: correlation matrix. Structural: white matter tract counts.
RDM
Representational Dissimilarity Matrix. Distance version (d=1-r) of the connectome. Fingerprints representational geometry.
TR (Repetition Time)
Time between fMRI snapshots, typically 0.5-3 seconds. More TRs = more data = more stable correlations.
Confounds
Non-neural signals (head motion, heartbeat, breathing) that contaminate BOLD data. Removed before computing connectivity.
NIfTI (.nii.gz)
Standard neuroimaging file format. 3D/4D voxel array + spatial header. Read by nibabel in Python.

Connectivity in BIDS

BIDS itself does not compute connectivity. BIDS is the filing system -- it standardizes how brain data is organized on disk so that analysis tools can find what they need automatically. Here is how the pieces fit together:

Step 1 -- BIDS organizes the raw data

Your fMRI scan comes off the scanner as a collection of DICOM files. BIDS converters (dcm2niix, HeuDiConv, ezBIDS) transform these into a standardized directory structure:

dataset/
  sub-01/
    anat/
      sub-01_T1w.nii.gz              # anatomical scan
    func/
      sub-01_task-rest_bold.nii.gz    # functional scan (BOLD time series)
      sub-01_task-rest_bold.json      # metadata (TR, echo time, etc.)

Without BIDS, every lab stores data differently and every tool needs custom configuration. With BIDS, any tool can automatically locate the functional scan and read the TR from the JSON sideband.

Step 2 -- BIDS Apps preprocess it

fMRIPrep (a BIDS App) takes this standardized input and produces preprocessed BOLD data -- motion-corrected, spatially normalized, with confound regressors computed. The output follows BIDS Derivatives conventions:

derivatives/fmriprep/
  sub-01/func/
    sub-01_task-rest_space-MNI_desc-preproc_bold.nii.gz
    sub-01_task-rest_desc-confounds_timeseries.tsv

Step 3 -- Connectivity analysis consumes BIDS Derivatives

This is where our module picks up. Tools like giga_connectome or nilearn take the preprocessed BOLD file, apply a parcellation atlas, extract regional time series, and compute the correlation matrix.

# How BIDS makes this possible -- no manual path configuration
from bids import BIDSLayout
layout = BIDSLayout('/path/to/dataset', derivatives=True)

# PyBIDS finds the right file automatically
bold_file = layout.get(subject='01', task='rest',
                       space='MNI152NLin2009cAsym',
                       desc='preproc', suffix='bold')[0]

# Then nilearn does the connectivity analysis
from nilearn import maskers, connectome
atlas = datasets.fetch_atlas_schaefer_2018(n_rois=200)
masker = maskers.NiftiLabelsMasker(atlas.maps)
time_series = masker.fit_transform(bold_file)
conn = connectome.ConnectivityMeasure(kind='correlation')
matrix = conn.fit_transform([time_series])[0]

Which BIDS Apps handle connectivity?

giga_connectome
Takes fMRIPrep derivatives, applies parcellation, computes connectivity matrices. The most direct BIDS-to-connectome tool.
Connectome Mapper 3
Full pipeline from raw BIDS to multi-resolution connectomes (83 to 1015 regions). Covers functional and structural.
nilearn
Python library (pip install, no Docker). Parcellation, time series extraction, connectivity matrices, visualization, GLM. Runs in Colab.
PyBIDS
Query engine for BIDS datasets. Finds files by subject, task, space, description. The bridge between BIDS organization and analysis code.

Without Docker?

Every tool listed above is installable with pip install. The Docker containers that BIDS Apps use are convenience packaging -- they bundle dependencies to avoid version conflicts. But the underlying code is Python. For connectivity analysis specifically, you need only: pip install nilearn nibabel pybids. That is what this tutorial demonstrates.

What you can do with this module

      
Explore network structure: Click within a diagonal block (e.g., V1 to V2, both in the Visual network) and see high correlation and tracking time series. Then click across blocks (e.g., V1 to mPFC, different networks) and see lower correlation. This demonstrates that the brain's network organization is visible in its correlation structure.

      
Test the effect of scan length: Drag the time points slider from 20 to 500. With few time points the matrix looks noisy. With many, the block structure becomes crisp. This is why longer scans give more reliable connectivity estimates.

      
Simulate different subjects: Change the random seed. The overall network structure stays stable but specific values shift -- demonstrating individual variation within shared architecture.

      
Toggle Fisher z-transform: Switch it on and notice values can now exceed 1 or go below -1. The matrix pattern looks similar but the scale changes -- this is the transformation needed for valid group statistics.

      
Upload your own data: Click "Upload CSV" to load a pre-computed correlation matrix (N x N, comma-separated) or raw time series (timepoints x regions). The module will visualize it using the same tools.

      
Export results: Click "Export matrix as CSV" to download the current connectivity matrix for use in other tools.
